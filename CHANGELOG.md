# Changelog

## Coolstuff 0.1.2

### Spore Creeper

- Added the `emessive_charge` layer, which smoothly appears while the Spore Creeper prepares to leap.
- Added separate block-damage settings for normal and parried Spore Creeper explosions. Normal block damage defaults to OFF; parried block damage defaults to ON.
- Spore Creepers now leave a vanilla-style lingering cloud containing their active effects after exploding.
- Spore Creepers now leap along a slightly higher and longer arc, giving players more time to react or escape.
- Spore Creeper explosions now release visible spore particles.

### English Localization

- Renamed Frostling to Frosted in the English localization.
